**漏了 `href="i/`**。报告页在 `<date>/` 内，`i/<id>.html` 是对的；但它是首页的**副本**，
同样路径被解析成 `/i/<id>.html` → **全部 404**（归档页里正常，所以只有从首页点才坏）。

**证据（2026-09-17 08:45 复核线上最新版）**：

head_sha `6f1a3a0a`，即远端 main 代码 —— **不含本工作区任何未提交改动**）。
- 首页 `index.html`：**26 个**卡片标题链接写的是 `i/<id>.html`，抽样 5 个 HTTP **全部 404**；
  同一批 id 在 `/2026-09-17/i/<id>.html` 下**全部 200**。
- 首页另有 13 个外链（`stock_news` 等无 id 条目）→ 这正是读者感受「**大部分**是 404」的原因。
- 对照：归档页 `/2026-09-17/2026-09-17.html` 里**同样 26 个** `i/` 链接**全部正常**
  （相对该目录解析正确）→ 坏点只在发布根副本。

### T2 再排查：v3「看不见」的**四个叠加原因**（安卓/所有平台通用）

段长 36~98 秒。故：

1. **闪 3 次只有 1.65 秒**（0.55×3）→ 读者抬眼时早闪完，只剩静止态 → 判为「没生效」；
2. **刚点播放 18 秒内毫无反应**（那两段没有卡片）→ 直接判为坏了；
3. 高亮背景被卡片自身规则盖回（特异性，见 §2.5）；
4. 横滑容器裁掉向外的描边/外发光（见 §2.5）。

**v5 修法（都不依赖「恰好看到那 1.65 秒」）**：进入段闪 3 次 → **之后转低频呼吸脉冲**
（2.6s 无限，任何时刻抬眼都在动）+ **卡片内插入「🔊 正在播」徽章**（DOM 元素，容器裁不掉、
特异性盖不住）+ 内向 outline + **播放器旁常驻提示条**。
