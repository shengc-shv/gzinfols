## 1. 红线与硬约定（**动手前必读**）

| 项 | 要求 |
|---|---|
| **时区** | 只认北京时间。用 `lib/utils/time.ts` 的 `todayKeyOf()` / `REPORT_TZ`。**不接受 env 覆盖、不回落系统时区**（CI runner 是 UTC）。禁止裸 `new Date()` 取日历日。 |
| **加密资产** | 零容忍：不移植、不渲染、不进契约。词表 `CRYPTO_WORDS`（`enrich/validator.ts`），渲染入口 `stripCryptoNews` 兜底。注意「Token贷」是银行信贷产品，**不要误删**。 |
| **银行主体信息** | 全项目禁止出现可反查具体银行的行名/简称/缩写/内部代号，一律写「某股分行」。 |
| **时间真实性** | 无真实 `publishedAt` 一律丢弃，**绝不用抓取时间兜底**。 |
| **业务相关性** | 内容须挂钩 客群/财富/私行/信贷，或是国家/省/市级商机政策。 |
| **架构门禁** | `lib/services/**` 禁 import `node:` 与 `lib/adapters`；契约层零逻辑；服务层禁 `process.env` / `Date.now()` / 裸 `new Date()`（用 `ctx.startTime`）。 |
| **测试** | 默认只跑受影响文件。**但涉及「窗口 / 日期 / 时区」的改动必须跑全量**（本机约 10 秒，很便宜）。 |
| **git commit message** | **禁用反引号** —— 本机是 zsh，双引号内的反引号会被当命令执行并从 message 中抹掉（已踩两次：`7b37470`、`ca47bac`）。 |
| **推送** | 不要未经用户授权 push。 |

### T2 · 音频播放时卡片「仍无闪烁」（P0，**用户明确反馈，最优先**）

用户 2026-09-17 反馈：播放音频时信息卡**依然没有闪烁**，并怀疑是「静态页面缓存」。
`8233277` 已把样式改为「整卡描边 + 进入时闪 3 次」，但**用户看到的现象未变**。

**⚠️ 排查顺序（请务必按此顺序，前两轮我曾跳过第 1 步导致误判）**

1. **先确认页面版本**（最可能的原因）
   - 本轮改动**尚未经过 CI 发布**。用户看到的可能是旧页面。
   - 判别：抓线上页面看是否含 `gz-audio-flash`（`curl -s <页面> | grep -c gz-audio-flash`）；
     旧页面计数为 0。
   - GitHub Pages 有 CDN 缓存 + 浏览器缓存；必要时加重跑 CI 或用无痕窗口验证。

2. **确认是否命中 `prefers-reduced-motion`**（第二可能）
   - `8233277` 的 CSS 里有 `@media (prefers-reduced-motion: reduce) { .audio-highlight { animation: none } }`。
   - **iOS「设置 → 辅助功能 → 动态效果 → 减弱动态效果」开启时，动画会被禁用**（这是刻意的无障碍降级）。
   - 若用户设备开了该开关 → 「不闪」是**预期行为**，需要与用户确认取舍。

3. **确认静止态描边是否可见**
   - 若描边**完全看不到** → 说明高亮根本没触发（不是动画问题），转查联动链路：
     段 id（`intro/hero/must/insight/risk/stock`）与卡片 `data-audio-section`（`must/insight/risk/stock`）**已实测匹配**；
     脚本 `generateAudioHighlightScript` 监听 `timeupdate`。
   - 已知限制：`stock` 段的卡片在「股市动态」标签页内，**非默认激活** → 听该段时不切页就看不到高亮。
     是否要「音频跟随自动切标签页」请向用户确认（会打断阅读）。

**相关文件**
- 样式：`lib/services/render/inline-player.ts` → `AUDIO_HIGHLIGHT_CSS`
- 脚本：同文件 → `generateAudioHighlightScript()`
- 注入：`lib/services/render/full.ts`（`<style>` 与 `</script>` 两处）
- 测试：`tests/audio-highlight.test.ts`（4 锁：动画 3 次、禁用 border、无障碍降级、联动链路）
