① 改渲染要动业务判定；② 单测要 import 整个渲染模块才能测分组；③ 与
`assemble/`（同为组装职责）形成两个入口。

### 为什么 C-2 排最前

P0-1 与 P0-2 的教训是：**"改动本身没问题"不等于"体系没问题"，而防线必须建在
产物层**。先立护栏，后面 3 个 phase 的千行搬移才有"行为不变"的客观判据；
反之先搬代码再补测试，一旦搬移引入回归，无法区分是搬移还是原有缺陷。

### 明确不做（本轮不建议）

- **`theme.ts` 拆分**：纯字符串常量，收益小、diff 噪声大，押后。
- **放宽「摘要≠标题复读」守卫**：属业务口径取舍（用户 2026-09-14 已裁决 B-1 不放宽），
